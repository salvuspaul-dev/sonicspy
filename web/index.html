Music carrier

Play any track and the data rides along inside it. The tones sit above the music in the same audio, so a phone across the room can decode the payload while everyone still hears the song.

No music loaded.
  1. Pick a track and press Play.
  2. Go to Send, choose Text or File, then press Broadcast loop.
  3. On the other device open Listen and hold it near the speaker.

Honest limits: louder, denser music makes the tones harder to hear, so raise the data level or leave ducking on. This survives music at ordinary listening levels, not a concert.

Agents and machines

Machines do not need to speak. The same link carries raw bytes, so two agents can exchange structured data faster than they could exchange words — and the CLI turns the link into plain files, so an agent that has no microphone can still take part.

Command line

# Encode a message or a file into a WAV an agent can play or hand to another agent
node tools/sonicspy-cli.mjs encode --text "hello" --out hello.wav --profile fast
node tools/sonicspy-cli.mjs encode --file report.json --out report.wav --profile turbo

# Decode a recording back into messages and files
node tools/sonicspy-cli.mjs decode --in recording.wav --out-dir received/

# Inspect the link without sending anything
node tools/sonicspy-cli.mjs selftest --profile turbo

Frame format

Every frame is self-describing, so a receiver can lock on to a broadcast already in progress. All fields big-endian.

FieldBytesMeaning
preamble16 symbolsalternating lowest and highest tone
sync3a5 c3 5a
version1protocol version, currently 1
flags1bit 0 binary payload, bit 1 gzip
msg id4random per message, groups the chunks
seq2frame counter within the message
chunk index2which piece this frame carries
chunk total2how many pieces the message has
payload length2bytes in this frame's payload
payloadnmessage bytes
CRC-162CCITT-FALSE over version…payload; bad frames are dropped

Why this is faster than talking

  • No rendering step. Bytes go straight into tones and straight back out.
  • One to many. A broadcast reaches every device in earshot at once, with no connection, handshake or pairing.
  • Compression. Structured payloads are gzipped before transmission, which on a slow channel buys more than any tweak to the modulation.

Diagnostics

The self-test runs the real modulator and demodulator inside this page, adds noise, and checks the message survives. It needs no microphone and no second device, so it is the quickest way to confirm the link works on this hardware.

How it works

Data is sent as MFSK: a short window of one pure tone per symbol, phases continuous so the sound is clean. The receiver measures the energy at each expected tone frequency with a Goertzel filter over a Hann window and takes the strongest — no carrier lock needed, only an estimate of where each symbol starts. A 16 symbol alternating preamble gives that timing, and every frame is protected by a CRC.
